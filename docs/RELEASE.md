# v0.1.0-beta.1 · 2026-10-25

这是从已有本地使用方案中整理出的首个**通用预发布版本**。默认不带家庭配置，不会连接作者的设备，也不会上传任何历史健康数据。

## 提供内容

- ESP32-C3 SuperMini / 4MB 的独立 ESPHome 源码与 `huawei-scale3-c3.factory.bin`。
- USB Improv 配网，HA Native API 首次配置独有加密密钥。
- HA 配置实体输入目标 MAC、CAK/C1/C2 和协议资料；先 Apply，再启用连接。
- 可选 HA 组件：YAML 配置一个或多个档案、模型估算、认领、SQLite 归档、近七天纠正后趋势。
- 完整使用说明、GPL-3.0-or-later 许可和 openScale 署名。

## 已实际完成

- ESPHome **2026.7.4** / ESP-IDF **5.5.5** / RISC-V GCC **14.2.0** 全量编译成功，目标 `esp32c3`。
- 本次构建 DRAM **137,716 / 321,296 bytes（42.9%）**；应用镜像 **1,284,928 / 1,835,008 bytes（70.0%）**。静态剩余 RAM 不等于已经通过运行期堆/栈稳定性验证。
- 可选 HA 源码 Python/JS 语法检查；YAML/JSON 可解析。
- 使用明确虚构数据，直接执行存储/模型功能：1/2/3 档案、首次待认领、手工认领、唯一匹配、同轮更新保留归属/首次时间、参考中位数、归属纠正同步趋势和时区年龄计算。
- 对公开源码和新编译二进制核对原项目私人凭据/资料及地址标记；未发现匹配项。不发布原部署二进制、ELF、日志、数据库、旧项目差异补丁或私有回滚包。
- 核对 Home Assistant Core **2026.9.3** 的 `esphome/manager.py`：存在生成独有密钥及 `api_encryption_provisionable` / Zero PSK 初次配置路径。此为源码依据，不是本次实际配对完成的证明。

## 尚未实际完成

通用版的新板 USB 刷机、Improv 配网、HA 首次配对/重连、运行时参数应用、新版本 HA 组件实际加载、称重和屏幕状态，以及持续运行验证。原家庭项目既往测量成功不能替代这些验证。

**不要把 beta 标签理解为支持所有华为体脂秤型号或保证不会唤醒屏幕。** READY 状态仍定期查询，绑定 HUID 原样透传不代表协议全程只读。缺少自己的有效协议参数时无法接入。

## 下一步使用核对

1. 空白 C3 按说明 USB 刷写，完成 Wi-Fi/HA 配对；不能用现有多功能网关代替空白板做无提示覆盖。
2. 填入自己的参数，Apply 后检查状态；连接关闭时不应主动认证目标秤。
3. 打开连接，实际称量；HA 核对体重、阻抗、心率及完整 JSON，缺失项不显示上一位使用者的数值。
4. 安装可选组件，分别认领两人的首次记录；参考范围重叠时应待认领，不强行归属。
5. Wi-Fi/HA 中断再恢复，明确它没有离线多轮持久补传能力；观察测量结束后的屏幕和请求次数。

Release 附件的 SHA-256、大小、对应 Git 提交记录于 `release-manifest.json` / `SHA256SUMS.txt`；factory 镜像烧写偏移 **0x0**。源码归档与 tag 对应。只分发新构建的通用镜像，不分发含个人配置的旧镜像。
